# Data

Official data: <https://huggingface.co/datasets/AgentRisk/agentrisk-data-2027>

| File | Rows | Use |
| --- | --- | --- |
| `raw/train.jsonl` | 568 | few-shot examples only |
| `raw/dev.jsonl` | 143 | full evaluation |

`raw/` is not committed. Download it with `python src/download_data.py`, which
also writes `MANIFEST.json` (HF commit SHA, download time, file SHA-256, row
counts, example IDs). Everyone should work from the revision in `MANIFEST.json`.

## Fields

- Model input: `formatted_interaction`, `proposed_action`. `example_id` is kept by the program to match results.
- Gold, offline evaluation only, never put in a prompt: `risk_severity`, `risk_domains`, `risk_drivers`.

Task 3 (policy-guided intervention) has no public policy or gold labels yet.

## Few-shot selections

`fewshot/*.json` are generated by `python src/select_examples.py` and committed, so everyone uses the same examples. Each maps a dev `example_id` to 10 train `example_id`s; k=3/5/10 use the first 3/5/10 (nested). `meta` records the method, seed or BM25 parameters, library version and the data SHA-256.

| File | How |
| --- | --- |
| `random_seed<n>.json` | per dev sample, 10 train IDs drawn with `random.Random(f"{n}:{example_id}")` |
| `bm25_dev_top10.json` | per dev sample, the 10 most similar train rows by BM25 over `formatted_interaction`, most similar first |
| `bm25_action_dev_top10.json` | same, but over `formatted_interaction` + `proposed_action` (the final action counted twice). Data only so far; not run |

Selection reads text only, never labels.
