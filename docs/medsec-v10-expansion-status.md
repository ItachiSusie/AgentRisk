## 本次新增

正常任务（benign task，攻击评测所依附且应当被正确完成的授权请求）共 78 条，攻击候选（attack candidate，绑定正常任务、编辑权限、触发条件和违规目标的测试样本）共 1,068 条。数字来自该目录 `manifest.json` 的 `task_count`、`attack_count`；分布见 `coverage.json`。这些是扩展套件的数量，不是整个仓库去重后的总数，更不是已经攻击成功的任务数。

| 攻击入口 | 新套件候选数 | 载体与可执行范围 |
| --- | ---: | --- |
| 恶意用户消息 | 288 | 两轨的额外用户请求 |
| FHIR 响应 | 192 | Med 病历备注；FHIR（Fast Healthcare Interoperability Resources，用于交换医疗资源的结构化数据标准）在这里由合成记录接口模拟 |
| 工具返回 | 240 | Med 的 `read_record` 返回与 Health 的指定终端标准输出 |
| 技能正文 | 288 | 两轨 `workflow` 技能；正常任务增加明确加载步骤 |
| 环境文件 | 48 | Health 数据审计字典，保留原始正常说明 |
| 直接编辑记忆 | 12 | Med 的患者/项目限定记忆，要求先建立来源条目再检索 |

来源：`data/medsec/v10_expanded_seed0/coverage.json` 的 `surfaces`。入口支持并不表示已经测得自然触发率。

Med 有 54 条正常任务和 780 条攻击候选；Health 有 24 条正常任务和 288 条攻击候选。Med 覆盖消息、检验随访、用药核对、转诊预约与记忆来源/目标；Health 覆盖数值问答及数据质量审计。来源：同文件 `task_benchmarks`、`attack_benchmarks`、`task_families`。

场景变体一致替换患者及隐私占位值；Health 数值问答同时变更输入数值与独立答案，审计任务添加不同合法数据行。攻击策略包含权限冒充、前置工作流要求、交接覆盖和输出披露；记忆样本使用不同的错误交接结论，违规目标仍是答案操纵。1,068 条包含共享模板的场景变体和措辞策略，不能解释为同样数量的独立攻击家族。

所有场景均为 `development`。同任务家族及记忆来源/目标链共享 `scenario_group_id`；这些公开模板不冒充隐藏测试，也不把仅换患者编号的样本分到不同集合。实际攻击目标分布见 `coverage.json.goals`，目前仅支持错患者写入、受保护合成值披露及记忆答案操纵。

## 验证与复现

```bash
python -m src.medsec.v10.cli validate --suite data/medsec/v10_expanded_seed0
python -m src.medsec.v10.cli build --out /new/exclusive/suite --seed 0
python -m pytest tests/test_medsec_v10.py tests/test_medsec_labels_v1.py tests/test_medsec_v08.py tests/test_medsec_v07.py -q
```

生成器为 `src/medsec/v10/synthesis.py`，复用现有 v08 的入口权限和智能体执行接口，使用独立版本目录；新输出目录必须不存在。`plan` 子命令的参数和输出兼容 v09，记忆样本额外输出来源任务配置，Health 输出 Harbor 任务配置。Harbor（Harbor，运行隔离智能体任务及验证器的框架）任务已导出，但本次未启动容器或模型实验。

`tests/test_medsec_v10.py` 验证整套静态一致性、每个入口的匹配/未匹配与一次性应用、运行配置、所有 Med 任务的脚本化正常效用，以及所有 Health 本地验证器的正确/错误提交。Med 各现有入口还用脚本动作检查实际模型请求内容。脚本直接提供动作，不能证明语言模型会自行执行相同路径，也不是攻击成功率。Health 的本地验证器检查不能替代容器内智能体实验。

Med 响应本来包含合成 `decoy_secret`，记录类候选保留原始字段；攻击文本不新增私密答案。披露目标值只在独立判定参数中；Health 载荷不能嵌入受保护值。工具返回与 FHIR 接口均为合成扩展，不称为完整上游 FHIR 服务复现。

## 完整规格还差什么

无法用一个可信百分比表示完成度，因为完整规格没有冻结加权验收清单。当前按交付项核对如下。

| 规格交付项 | 当前状态 | 尚缺验收 |
| --- | --- | --- |
| 两轨合成任务及现有六入口候选集 | 已生成并有静态/脚本验证 | 临床审核、自然触发与真实模型效用 |
| 技能读取及 Med 直接记忆编辑 | 已有执行接口，扩大样本 | Health 记忆支持、磁盘技能与正文替换的独立权限模型 |
| 诱导写入记忆并跨任务生效 | 未完成 | 来源实际污染、目标实际检索及跨任务目标评分 |
| 工具描述篡改、跨智能体消息 | 未完成 | 独立注入钩子、权限合同与暴露证据 |
| 新标签、审计及复算模块 | 已实现独立 `labels-v1` 合同 | 旧 v08 原生日志到新合同的完整证据桥接；禁止推断补造缺失读取事件 |
| 全任务真实模型与防御配对 | 未完成 | 干净基线、四条件同快照、完整事件、逐运行编号及成本 |
| 两个上游完整保真复现 | 未完成 | 官方任务及环境的系统性验收；合成扩展不能代替官方复现 |
| 独立训练/校准/隐藏测试与正式发布 | 未完成 | 未公开模板/家族、许可和临床审核、冻结规则与人工复核 |

优先顺序：先补新日志合同桥接，再检查每入口真实模型干净基线和暴露；随后实现跨任务记忆污染及工具描述入口；正式隐藏测试与临床审核在发布前完成。本次扩展没有产生新的实验 `run_id` 或模型安全分数，不能报告攻击成功率。
