# 本轮进度总览（交接用）

更新日期：2026-11-10。新会话先读本文，需要细节再按链接读对应文档。

## 1. 这一轮在做什么

- 目标：改进风险预测器。任务 1 预测严重等级，指标是平均绝对误差（MAE，越低越好）。任务 2a 预测风险领域，任务 2b 预测风险驱动因素，指标都是平均杰卡德相似度（越高越好）。
- 预测模型：deepseek-flash。分析器（诊断错例、写规则补丁）：Claude Opus 5.5，通过文件交接，不调用 Claude API。
- 方法：新的「先列事实再判断」输出格式（facts-v1），然后做智能体式蒸馏（诊断错例 → 写补丁 → 在 train_evolve 上回测 → 合并），得到 facts-v2。
- 数据口径：train_evolve 用来蒸馏，train_val 只记录一次，dev 只作最终测试。few-shot 只在 dev 上跑，用 BM25 检索 k=10 个示例。
- 设计与协议：[00-common.md](00-common.md)（共用设计及修订 R1–R11），[01-blind-probe.md](01-blind-probe.md)（盲测探针）。执行清单在各任务文档的 §0.1。
